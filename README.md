 # Wellness Pulse — Student Mental Health Project

## About the Project
A machine learning project exploring student social media usage and mental health-related data.

## Features
- Data analysis and preprocessing
- Machine learning model integration
- Web interface using HTML, CSS, and JavaScript

## Technologies Used
- Python
- Machine Learning
- HTML
- CSS
- JavaScript
- Jupyter Notebook

## Project Files
- `main.py` — Python application
- `index.html` — Main web page
- `ML_Project.html` — Project interface
- `script.js` — JavaScript functionality
- `style.css` — Styling
- `mental_health.ipynb` — Notebook
- `Mental_Health_Model.pkl` — Saved model
- `requirements.txt` — Dependencies

## How to Run
1. Install Python.
2. Install the required packages using `pip install -r requirements.txt`.
3. Follow the instructions in the application code to start the project.

## Disclaimer
This project is for educational purposes only. It does not diagnose mental health conditions or replace professional care.
